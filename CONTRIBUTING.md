# Guia de Contribuição

Obrigado por considerar contribuir com este projeto. Sua ajuda é bem vinda.

## Como contribuir

### Reportando bugs

Antes de abrir uma issue, verifique se o bug já não foi reportado. Ao abrir, inclua:

- Descrição clara do problema
- Passos para reproduzir
- Comportamento esperado versus observado
- Ambiente (sistema operacional, versão do Node.js, etc.)

### Sugerindo melhorias

Issues de melhoria devem descrever:

- O problema que você está tentando resolver
- A solução proposta
- Alternativas consideradas, se houver

### Enviando código

1. Faça um fork do repositório
2. Crie um branch descritivo: `git checkout -b minha-feature`
3. Faça suas alterações
4. Execute os testes: `npm test`
5. Execute o linter: `npm run lint`
6. Commit com mensagem clara e descritiva
7. Abra um Pull Request

### Padrões de código

- Siga o estilo existente do código
- Escreva testes para novas funcionalidades
- Mantenha a cobertura de testes existente
- Documente funções públicas quando necessário

## Revisão

Pull Requests serão revisados assim que possível. Feedbacks construtivos podem ser solicitados para garantir a qualidade do código.
