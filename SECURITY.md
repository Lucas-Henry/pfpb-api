# Política de Segurança

## Reportando vulnerabilidades

Valorizamos a segurança deste projeto e agradecemos qualquer esforço para identificar e reportar vulnerabilidades de forma responsável.

Se você encontrar uma vulnerabilidade de segurança, por favor, reporte através das issues do GitHub com o label `security`. Não crie issues públicas para vulnerabilidades críticas.

Alternativamente, envie um email para os mantenedores do projeto descrevendo o problema encontrado.

## O que esperar

Após o reporte, você receberá uma confirmação em até 48 horas. Trabalharemos para resolver o problema o mais rápido possível e manteremos você informado sobre o progresso.

## Práticas de segurança

- Mantenha as dependências atualizadas
- Não compartilhe tokens, chaves de API ou credenciais no código
- Utilize variáveis de ambiente para configurações sensíveis
- Revise o código de contribuições externas antes de integrar
